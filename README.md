# Spa Oasis — Преміальний спа-салон та онлайн-запис

Сучасний повнофункціональний веб-додаток для спа-салону, який дозволяє гостям переглядати каталог процедур, реєструватися у власному кабінеті та бронювати візити онлайн, а адміністраторам — керувати послугами та відстежувати статистику.

> **Демо:** [Посилання на твій деплой на Vercel з'явиться тут]

## Можливості

- 🔐 **Аутентифікація** — безпечна реєстрація, логін та logout на базі NextAuth.js (з використанням bcrypt).
- 👥 **RBAC (Role-Based Access Control)** — розмежування прав доступу для Адміністраторів та Гостей (User).
- 🌿 **Керування послугами** — повний CRUD для спа-процедур (створення, редагування, перегляд, видалення) з поділом на категорії (Масаж, Обличчя, Тіло, Догляд).
- 🗓️ **Бронювання візитів** — система створення замовлень (Booking та BookingItem) із прив'язкою до користувача та процедур.
- 🎨 **Сучасні інтерактивні форми** — швидка обробка та клієнтська валідація за допомогою React Hook Form, Zod та інтерактивних сповіщень Sonner.
- 🛡️ **Безпека та захист** — сувора серверна валідація, санітизація вхідних даних проти XSS, HTTP-заголовки безпеки (`security headers`).
- 🚀 **Оптимізація та SEO** — миттєве завантаження фонових зображень через `next/image`, динамічні метадані для кожної процедури, автоматична генерація `robots.txt` та динамічного `sitemap.xml`.

## Технологічний стек

- **Frontend:** Next.js 16 (App Router, Turbopack), React 19, Tailwind CSS
- **Backend:** Next.js Route Handlers (API), NextAuth.js (Credentials Provider)
- **База даних:** MongoDB Atlas + Mongoose ODM (збереження схем Booking, Service, User)
- **Валідація:** Zod (клієнтська та серверна схеми)
- **UI feedback:** Sonner (моментальні toast-сповіщення)
- **Деплой:** Vercel + GitHub
